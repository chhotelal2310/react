A Higher-Order Component (HOC) is a function that take a component as an argument and return a new enhanced component with additional functionality.
Syntax:const EnhancedComponent = higherOrderComponent(OriginalComponent);

Advantages of HOC:
1.Reuse code across multiple components.
2.Reduce code duplication.
3.Keep components clean and simple.
4.Easy to maintain.
5.Separate UI from business logic.

Disadvantages of HOC:
1.Nested Wrappers
Ex. withAuth(withTheme(withLoading(Profile)));
2.Harder to debug.
3.Props Collision



Example:
const User = ({ users }) => {
  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
};

const withLoading = (Component) => {
  return function ({ loading, ...props }) {
    if (loading) {
      return <h2>Loading...</h2>;
    }
    return <Component {...props} />;
  };
};

const UserWithLoading = withLoading(User);

export default UserWithLoading;

Use:
<UserWithLoading loading={true} users={[{ id: 1, name: "Rahul" }]} />



What is children Prop in React?
The children prop is a special prop in React used to pass content (text, JSX, components, elements) between the opening and closing tags of a component.

Syntax: <Component>Content Here</Component>;

/*********************************************** Lazy Loading *******************************/
Example with routing:
import React, { Suspense } from "react";
import { BrowserRouter, Routes, Route } from "react-router-dom";

const Home = React.lazy(() => import("./pages/Home"));
const About = React.lazy(() => import("./pages/About"));
const Contact = React.lazy(() => import("./pages/Contact"));

function App() {
  return (
    <BrowserRouter>
      <Suspense fallback={<h2>Loading page...</h2>}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/about" element={<About />} />
          <Route path="/contact" element={<Contact />} />
        </Routes>
      </Suspense>
    </BrowserRouter>
  );
}

export default App;


Benefits of React.lazy()
1. Faster initial load
2. Better performance
3. Smaller bundle size
4. Better user experience

Limitations of React.lazy()
1. It works only for default export
const About = React.lazy(() => import("./About"));
About.js
export default About;

Not directly for named export:
export const About = () => {};

2. It must be used inside Suspense: If not, React will throw an error.
3. It is for components only: You cannot use React.lazy() for normal functions, variables, or hooks.
                              It is only for React components.



How to use named export with React.lazy()
export const About = () => {
  return <h1>About Page</h1>;
};
const About = React.lazy(() =>
  import("./About").then((module) => ({
    default: module.About,
  }))
);



What is code splitting?
Code splitting means dividing your JavaScript into smaller parts so that only the needed part is loaded when required. React.lazy() helps with this.

What happens if Suspense is not used?
React will throw an error because it does not know what to show while the lazy component is loading.

Q.Can I import an SVG file as a React Component?
Yes. React allows you to import an SVG file as a component and use it just like a normal React component.
Example:
import { ReactComponent as Logo } from "./logo.svg";

function App() {
  return <Logo />;
}

Advantages of SVG
1.Scalable without losing quality
2.Small file size
4.Easy to customize
5.Can change color with CSS
6.Can animate
7.Great for logos and icons


OR

SVG can be imported as a React component, allowing the SVG to behave like a reusable React component. This makes it possible to pass props,
apply styles, handle events, and customize the SVG dynamically, which is not possible when using it as a normal image.
import Logo from "./logo.svg?react";

function App() {
  return (
    <Logo
      width={100}
      height={100}
      className="logo"
    />
  );
}

useEffect
useEffect is a React Hook used to perform side effects in functional components. It runs after React renders the component and can be controlled using a dependency array to decide when the effect should run.
What is a Side Effect?
A side effect is any operation that affects something outside the React component.
Examples:
a.API calls
b.Fetching data
c.Setting timers








Syntax
useEffect(() => {

}, []);


Cleanup Function
useEffect(() => {

  return () => {

  };

}, []);

Note: The returned function is called the cleanup function.

Timer Example
Without cleanup:
useEffect(() => {

  setInterval(() => {
    console.log("Hello");
  }, 1000);

}, []);

Note: The timer keeps running even if the component is removed.


With cleanup:
useEffect(() => {

  const id = setInterval(() => {
    console.log("Hello");
  }, 1000);

  return () => {
    clearInterval(id);
  };

}, []);

Note: Now React clears the timer when the component unmounts.

Because useEffect expects its callback function to return either nothing (undefined) or a cleanup function.
An async function always returns a Promise, which React cannot use as a cleanup function.
syntax is:
useEffect(() => {
  // Side effect code

  return () => {
    // Cleanup function (optional)
  };
}, []);

Note:The callback passed to useEffect should return only one of these two things:
1.Nothing (undefined)
2.A cleanup function
Like this:
useEffect(() => {
  console.log("Component Mounted");

  return () => {
    console.log("Component Unmounted");
  };
}, []);
