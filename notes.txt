useContext is a React Hook used to consume data from Context without passing props through every intermediate component. We create a Context using createContext, provide data using a Provider, and read it using useContext. It is commonly used for shared data such as authentication, themes, and language settings. Context avoids prop drilling, but Context itself is not a complete replacement for state-management libraries.

useContext rules

1. useContext is a Hook.
2. Call it at the top level of your component/custom Hook.
3. It reads the nearest matching Context value.
4. Context avoids prop drilling.
5. Context itself is not state.
6. Provider supplies the value.
7. Consumers read the value.
8. Changing the provided value can update consumers.

Passing props through components that don't actually need the data, just so a deeper component can receive it.

        data needed by D

const UserContext = createContext();

Step 2 — Provide data

import { useState } from "react";
import UserContext from "./UserContext";

function UserProvider({ children }) {
  const [user, setUser] = useState({
    name: "Chhotelal",
    role: "Developer"
  });

  return (
    <UserContext.Provider value={{ user, setUser }}>
      {children}
    </UserContext.Provider>
  );
}

export default UserProvider;


Step 3 — Consume using useContext

import { useContext } from "react";
import UserContext from "./UserContext";

function Profile() {
  const { user } = useContext(UserContext);

  return <h2>Hello {user.name}</h2>;
}

Context and useReducer

For larger state management, Context is often combined with useReducer.

For example:

const initialState = {
    count: 0
};

Reducer:

function reducer(state, action) {

    switch (action.type) {

        case "INCREMENT":
            return {
                ...state,
                count: state.count + 1
            };

        case "DECREMENT":
            return {
                ...state,
                count: state.count - 1
            };

        default:
            return state;
    }
}

Provider:


function CounterProvider({ children }) {

    const [state, dispatch] = useReducer(
        reducer,
        initialState
    );

    return (
        <CounterContext.Provider
            value={{
                state,
                dispatch
            }}
        >
            {children}
        </CounterContext.Provider>
    );
}



Consumer:
function Counter() {

    const {
        state,
        dispatch
    } = useContext(CounterContext);

    return (
        <>
            <h1>{state.count}</h1>

            <button
                onClick={() =>
                    dispatch({
                        type: "INCREMENT"
                    })
                }
            >
                +
            </button>
        </>
    );
}

55. A simple interview answer to memorize

If the interviewer asks:

"Explain useContext in React."

A strong answer would be:

"useContext is a React Hook that allows components to consume values from a React Context without passing those values through intermediate components using props. It is commonly used to solve prop drilling and share values such as authentication information, themes, localization, and application configuration. We create a Context using createContext, provide a value using its Provider, and consume that value using useContext. Context itself is primarily a value-sharing mechanism, so for state management it is commonly combined with useState or useReducer. For performance, large or frequently changing contexts should be designed carefully, and unrelated state can be split into separate contexts."
