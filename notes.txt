Code splitting is a technique of splitting a large JavaScript bundle into smaller chunks and loading those chunks only when required,
which improves the application's initial loading performance.
Example:
const Dashboard = lazy(() => import("./Dashboard"));
Here, Dashboard can be placed in a separate chunk and loaded when React needs it.

Q.How do you implement code splitting in React?
React commonly uses: React.lazy() with: dynamic import();
Example:
import { lazy, Suspense } from "react";

const Dashboard = lazy(() => import("./Dashboard"));

function App() {
  return (
    <Suspense fallback={<p>Loading...</p>}>
      <Dashboard />
    </Suspense>
  );
}

Q.Why do we use Suspense with React.lazy?
React.lazy() loads a component asynchronously. Suspense provides fallback UI while that component is waiting to become available.
Example:
<Suspense fallback={<p>Loading...</p>}>
  <Dashboard />
</Suspense>

Flow:
Dashboard requested
       ↓
Not ready
       ↓
Show Loading...
       ↓
Chunk downloaded
       ↓
Dashboard ready
       ↓
Render Dashboard

Q.What is the difference between import and dynamic import?
Static imports are evaluated as part of the module's normal dependency graph, while dynamic imports return
a Promise and provide a split point that bundlers can use for code splitting.
Static import:
import Dashboard from "./Dashboard"; ==>It's part of the module's static dependency graph.
Dynamic import: import("./Dashboard");==> It loads the module asynchronously and can create a separate chunk.

Q.What is route-based code splitting?
Route-based code splitting means loading the JavaScript for a page only when the user navigates to that route.
Example:
const Dashboard = lazy(() => import("./Dashboard"));

Then:
<Route
  path="/dashboard"
  element={<Dashboard />}
/>

Q.What is the difference between code splitting and lazy loading?
Code splitting divides the application into multiple chunks, while lazy loading means loading those chunks only when they are needed.
Code Splitting
→ Divide

Lazy Loading
→ Load later

What is a chunk?
A chunk is a JavaScript file generated by a bundler that contains part of your application's code.

For example:
main.js
dashboard.js
reports.js
admin.js

Q.What is the diffrent bewtween Code Splitting, Minification and Tree Shaking.

Code Splitting → splits files

Minification → reduces file size

Tree Shaking → removes unused code
